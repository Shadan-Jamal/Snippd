Import

Choose a Snippd backup file to merge. New titles are inserted; when titles collide, the newer updated_at wins. import

How it works

  • Download .db… opens the browser save dialog so you pick the destination folder/file.
  • Save to default folder writes under ~/.snippd/ with no path typing.
  • Import uploads the selected .db and merges it (browsers never expose absolute disk paths).
  • CLI equivalents: snippd export [file] and snippd import <file>.
