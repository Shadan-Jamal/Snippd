Setup tips

config setup

  • Snippd reads editors only from ~/.snippd/config.json.
  • Use SNIPPD_VISUAL for GUI editors with --wait.
  • Use SNIPPD_EDITOR for terminal editors like vim or nvim.
  • On Windows, prefer a full path to the .exe, not a .cmd shim.
